HAVEN MARKET — RESPONSIVE E-COMMERCE FRONTEND

PAGES
- index.html      Responsive store homepage
- products.html   Product listing, category filters, sorting
- product.html    Product details, quantity selector, add to cart
- cart.html       Cart items, quantity controls, subtotal and delivery
- checkout.html   Responsive checkout form and order summary
- login.html      Login form UI
- register.html   Registration form UI
- css/style.css   Shared design system, Flexbox, Grid and breakpoints
- js/products.js  Sample product catalogue
- js/main.js      Cart, filtering, sorting, form validation and navigation
- images/         Folder reserved for your own image assets

HOW TO RUN
1. Extract the ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html using Live Server (recommended), or open it directly in a browser.
4. Use Shop to filter categories, open a product, add it to cart, and test checkout.

ASSIGNMENT FEATURES
- CSS Flexbox and CSS Grid layouts
- Mobile-first responsive breakpoints
- Reusable product cards and navigation
- Category filter UI and price sorting
- Product details with purchase panel
- Responsive checkout form with HTML validation
- Cart saved in browser localStorage
- Hover and keyboard focus states
- No Bootstrap or external CSS framework
- Browser zoom-friendly flexible layouts

IMPORTANT
This is a front-end educational demo. Cart data is stored in localStorage in your browser.
Login, registration, newsletter and checkout do not connect to a real server or payment gateway.
Product visuals are CSS/emoji placeholders; replace them with your own images in the images folder if required.
